01 · 읽기

규칙과 적용 자리를 봅니다

문서 종류를 고르고 부분을 펼치면 규칙과 그 이유, 표본 문서에서 적용된 자리가 나옵니다.

02 · 의견

현장과 맞는지 알려 줍니다

동의·조건부·현장은 다릅니다 가운데 하나를 고르고 사유를 한두 줄 남깁니다. 규칙에 없는 요령은 노하우로 올립니다.

03 · 반영

검토를 거쳐 규칙이 됩니다

모인 의견은 근거와 함께 검토해 규칙에 반영합니다. 바뀐 규칙은 웹앱과 경량 스킬에도 실립니다.

규칙만 내려받아 쓰던 AI에 붙이세요

웹앱이나 플러그인 없이 평소 쓰는 AI에 규칙만 알려 주고 싶을 때 쓰는 묶음입니다. 마크다운 파일 14개라 가볍습니다. 문서를 쓸 일이 생기면 AI가 필요한 규칙 파일만 골라 읽습니다.

Claude Code 알아서 켜짐

압축을 풀어 나온 artifact-intelligence-rules 폴더를 ~/.claude/skills/ 아래에 그대로 둡니다. 스킬 폴더를 처음 만들었다면 Claude Code를 한 번 다시 시작하세요.

claude.ai 알아서 켜짐

사용자 지정(Customize) → 스킬(Skills)에서 내려받은 zip 파일을 풀지 말고 그대로 올립니다.

Codex · OpenClaw 알아서 켜짐

압축을 풀어 나온 폴더를 ~/.agents/skills/ 아래에 둡니다. 두 도구 모두 이 폴더를 읽습니다. 새 스킬이 보이지 않으면 Codex를 다시 시작하세요.

ChatGPT · Gemini 직접 불러 씀

스킬이 저절로 켜지지는 않습니다. references 폴더의 md 파일을 프로젝트나 Gem의 지식 파일로 올리고, 지시문에 “문서를 쓸 때 이 규칙을 따르라”고 적어 두세요.

스킬은 AI에게 지시를 건네는 파일입니다. 받으신 뒤 내용을 한 번 훑어보고 쓰세요. 이 묶음에는 실행 코드가 없습니다. 업무용 PC에 설치할 때는 기관 정보보안 지침을 먼저 확인하세요.
