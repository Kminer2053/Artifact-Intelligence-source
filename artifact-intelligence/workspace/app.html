문서지능시작하기 전에 — 정보 이용 안내

넣으신 자료와 초안은 지금 만드는 문서에만 씁니다. 10분간 반응이 없거나 파일을 받으시면 세션이 끝나고, 자료·초안은 그때 자동으로 지웁니다.

초안은 AI 가 씁니다. 기본 모델을 쓰시면 넣으신 내용이 해외 AI 서비스(미국)로 전달돼 처리됩니다 — 저희 서버도, 제공자(Featherless)도 프롬프트를 저장하지 않습니다. 본인 API 키를 넣으시면 브라우저가 직접 불러 서버조차 내용을 안 봅니다.

주민등록번호 같은 민감정보나 불필요한 개인정보는 적지 마세요. 문서에 쓸 사실과 숫자면 됩니다.

나온 문서는 어디까지나 초안입니다. 확인하고 제출하는 책임은 쓰시는 분께 있고, 법률·행정 자문이 아니며 정확성도 보장하지 않습니다.

다듬으신 내용이 규칙을 개선하는 데 도움이 될 만하면, 그때 동의를 여쭙고 동의하시면 이름·연락처를 지운 익명으로만 남깁니다.

자세한 내용은 이용약관·개인정보 처리방침. ‘동의하고 시작’을 누르시면 이 안내와 약관에 동의하신 것으로 봅니다.

내 API 키로 쓰기

아래 설정은 이 브라우저에만 저장되고 서버로 보내지 않습니다. 모델 호출은 이 브라우저가 제공자에 직접 합니다 — 서버는 키도 내용도 보지 못합니다. 키를 비우고 저장하면 지워집니다.
