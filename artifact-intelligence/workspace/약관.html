이용약관 · 개인정보 처리방침

쉽게 읽히도록 간단히 적었습니다. 정식 서비스가 되면 더 자세한 문서로 갱신됩니다.

문서지능은 공공부문 AX(AI 전환)를 넓히려는 MVP(시범) 프로젝트입니다. 정식 서비스가 아니라 기능을 시험하는 단계라, 아래 내용도 그 범위에서 적용되며 예고 없이 바뀌거나 멈출 수 있습니다.

이용약관

1. 어떤 서비스인가요

의도와 자료를 주시면 공공기관 문서 초안을 만들어 드립니다. 시범 단계라 ‘있는 그대로’ 제공합니다.

2. 만든 문서의 책임

나온 문서는 초안입니다. 사실·형식을 확인하고 제출하는 일, 그리고 그 결과의 책임은 쓰시는 분께 있습니다. 이 서비스는 법률·행정 자문이 아닙니다.

3. 하지 말아 주세요

남의 권리를 침해하거나 법을 어기는 자료는 넣지 마세요.

4. 책임의 한계

시범 서비스라 정확성이나 계속 이용을 보장하지 않습니다. 이용하다 생긴 손해에 대해서는 법이 허용하는 범위에서 책임지지 않습니다.

개인정보 처리방침

1. 무엇을 받나요

문서를 만들 자료를 받습니다 — 그 안에 개인정보가 들어 있을 수 있습니다.

AI 모델은 기본으로 저희가 제공하니 따로 준비하지 않으셔도 됩니다. 다만 기본 모델 처리가 꺼려지거나 쓰시던 모델의 API 를 이용하고 싶으시면, 직접 API 키를 넣으실 수 있습니다. 넣으신 키는 브라우저에만 두고 서버에 저장하지 않습니다.

2. 어떻게 쓰고 언제 지우나요

문서 초안을 만드는 데만 씁니다. 문서 한 건이 한 세션이고, 세션이 끝나면(10분 무동작 또는 내려받기) 자료와 초안을 자동으로 지웁니다.

기본 모델을 쓰셔도 저희 서버는 프롬프트를 저장하거나 들여다보지 않습니다 — 세션이 끝나면 함께 지워집니다. 초안을 만들 때 그 내용은 경북IT융합산업기술원이 운영하는 공공 AI 허브(Open AI Service Hub)의 모델(EXAONE)로 전달되어 처리됩니다. 허브의 프롬프트 보관 정책은 별도로 공개돼 있지 않으니, 민감한 개인정보는 넣지 않으시길 권합니다.

3. 어디서 처리되나요 (국외 이전 없음)

초안을 만들 때 넣으신 내용이 아래로 전달됩니다.

  • 받는 곳: Open AI Service Hub (경북IT융합산업기술원 운영, 국내)
  • 처리 모델: EXAONE (LG AI연구원)
  • 목적: AI 초안 생성
  • 시점: 초안을 요청하실 때
  • 방법: HTTPS(TLS)로 전송 구간 암호화

국내에서 처리되어 국외로 이전되지 않습니다. 본인 API 키를 쓰시면 브라우저가 직접 호출해 이 경로를 거치지 않습니다.

4. 남기는 정보

다듬으신 내용이 규칙을 개선하는 데 도움이 될 만하면, 동의하신 경우에만 이름·연락처를 지운 익명으로 남깁니다.

5. 문의

시범 단계라 계정이 없고, 세션이 끝나면 자료가 사라져 따로 삭제 요청이 필요 없습니다.

쓰시다 불편하거나 문의할 점이 있으면 GitHub 이슈에 남겨 주세요. 시범 단계라 이슈로 받은 의견이 개선에 큰 도움이 됩니다.
